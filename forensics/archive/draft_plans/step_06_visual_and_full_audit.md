# Step 6 draft plan: evidence and structural visualization

## Purpose

Provide a compact, navigable reconstruction view rather than an uninterpretable giant hairball. Use 1000 curated nodes, chosen for strength, structural coverage, and diversity, with cluster paths annotated.

## Rules

- Do not render all 187,242 payloads as one uninterpreted graph.
- Use L1/L2/L3/L4 clusters and time/context partitions.
- Each rendered edge must link to CSV/JSON evidence.
- Colors encode relation family, not narrative behavior.
- Huge motifs must show explicit pivot count, edge type, exemplar row IDs.
- Visualization must show sample context, trigger, precision.
- Mark no-identity and no-causation where needed.

## Components
1. Row-level repalcement evidence viewer.
2. Cluster path explorer.
3. Time context bridge
4. Operation family panorama.
5. Pivot histogram and bridge report.
6. External event context globe.
