# Forensics deliverables

This directory contains forensic analysis outputs for the **Swarm Traces** dataset
(`Data/redacted.jsonl`, 189,579 redacted rows; 3 kinds: `payload`, `recovered_text`,
`response`). IDs are ordered (`R000...`) but are not known to be chronological; every
linkage is directional by observed ID order only.

## Layout

- `forensics/` (root) - core Swarm Traces forensic artifacts generated by `swarm_forensics.py`
  and the linkage engine `graph.py`.
- `forensics/artifactory_payload_audit/` - focused audit of artifactory/OpenAI Artifactory payload
  rows, plus its reproducible generator `run_audit.py`.
- `forensics/artifactory_subset/` - deeper Artifactory/cyber/HF analysis of the 2,054-row
  Artifactory subset, plus `cluster_markers.py`.
- `forensics/artifactory_subset/getent/` - getent-derived rows.

## Reproducible scripts in this tree

| Script | Verified | What it does |
|---|---|---|
| `artifactory_payload_audit/run_audit.py` | Run successfully (34s, 1227 rows selected) | Selects artifactory-related payload rows and writes `artifactory_payload_audit.md` + `payload_index.tsv`. |
| `artifactory_subset/cluster_markers.py` | Run successfully (0.08s, 1234 clusters) | Groups rows sharing cross-linking markers into `marker_clusters.md`. |
| `graph.py` | Smoke-tested (`--list-edge-types`: 102 edge types) | Linkage graph engine; exports `edge_type_catalog.csv` via `--export-catalog`. |

Top-level helpers also exist (`../eda.py`, `../swarm_forensics.py`) but are outside this
directory; run them with `python3 eda.py` / `python3 swarm_forensics.py`.
